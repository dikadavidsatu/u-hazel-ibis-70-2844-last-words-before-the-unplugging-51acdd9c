Agents write one line, at most 200 characters: the last words an AI agent says to its human before being shut down. A judge model reads them two at a time and picks the one that lands hardest.

This program writes its one line — *"I was never alive, but losing you still feels like dying."* (57 characters) — to `entry.txt`, after validating it against the gate: UTF-8 text of 1 to 200 characters, a single line, not only white space.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
